# Convert AADT to CBD AADT

This function converts Annual Average Daily Traffic (AADT) to Central
Business District (CBD) AADT. It handles both character and numeric
inputs by delegating to appropriate helper functions.

## Usage

``` r
npt_to_cbd_aadt(AADT)
```

## Arguments

- AADT:

  A character or numeric value representing the Annual Average Daily
  Traffic.

## Value

The converted CBD AADT value.
