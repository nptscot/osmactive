# Get the OSM network functions

Get the OSM network functions

## Usage

``` r
get_traffic_calming(osm_points, filter = TRUE)
```

## Arguments

- osm_points:

  An sf object with the OSM network

- filter:

  Whether to filter the results to only include traffic calming measures

## Value

A data frame with the OSM network relevant for active travel
