# Count how many bus lanes there are

Count how many bus lanes there are

## Usage

``` r
count_bus_lanes(osm)
```

## Arguments

- osm:

  An sf object with the road network

## Value

The number of bus lanes

## Examples

``` r
osm = osm_edinburgh
count_bus_lanes(osm)
#> Matched these columns: 
#> numeric(0)
```
